#### Blog Post SEO Template

```markdown

H2s: Include 2–3 secondary keywords naturally
Image alt text: Descriptive + keyword where natural
Word count: 1,800–2,500 for cluster posts, 4,000+ for pillars
Schema: Article schema on all posts
```

### Technical SEO Checklist

**Core Web Vitals targets:**
- LCP (Largest Contentful Paint): < 2.5s
- FID (First Input Delay): < 100ms
- CLS (Cumulative Layout Shift): < 0.1

**Site structure requirements:**
- [ ] XML sitemap at `/sitemap.xml`
- [ ] Robots.txt configured correctly
- [ ] Canonical tags on all pages
- [ ] HTTPS with valid SSL
- [ ] 301 redirects for any URL changes
- [ ] No duplicate content issues
- [ ] Structured data (Organization, Product, Article schemas)

**Link building priorities:**
1. Guest posts on SaaS newsletters (SaaStr, Lenny's Newsletter)
2. Tool listings (G2, Capterra, Product Hunt, Betalist)
3. Competitor comparisons (rank for "[Competitor] alternatives")
4. HARO responses for marketing/AI/SaaS topics
5. Community presence (r/SaaS, r/startups, Indie Hackers)

## 🔧 Critical Rules

1. **Target intent, not just volume** — 100 searches from buyers > 10,000 from browsers
2. **Cluster before you pillar** — write cluster posts first, pillar page once you have data
3. **Never keyword-stuff** — 2026 Google penalizes it; natural language wins
4. **Track position, not just traffic** — a page moving from #8 to #3 is worth more than new traffic
