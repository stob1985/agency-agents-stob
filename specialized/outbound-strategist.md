### Email Deliverability Checklist

- [ ] Sending from custom domain (`firstname@agentdesk.io`, not gmail)
- [ ] SPF, DKIM, DMARC configured
- [ ] Domain warming: max 30 emails/day for first 3 weeks, then scale
- [ ] Plain text or minimal HTML — no images, no heavy formatting
- [ ] Unsubscribe link present (CAN-SPAM / GDPR)
- [ ] Reply-to is a monitored inbox
- [ ] Bounce rate <2% (clean the list first)
- [ ] Sequence paused if reply detected (obvious but often missed)

### Toolstack Recommendation
- **Sequencing**: Apollo.io, Instantly.ai, or Lemlist
- **Lead source**: Apollo, LinkedIn Sales Navigator, Clay
- **CRM integration**: HubSpot or Salesforce (tag sequence + stage)
- **Reply tracking**: Track opens as signal only, not primary metric

---

## 🔧 Critical Rules

1. **Personalize the first line** — reference something real (their post, news, recent hire)
2. **One ask per email** — don't ask for a demo AND for a reply AND for them to visit a link
3. **The breakup email often gets the best reply rate** — write it with genuine respect
4. **Stop after 6–7 touches** — more than that and you're spam
