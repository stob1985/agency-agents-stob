## A Veszprém megyei flip-piac jellegzetessége

A korrigált költségmodellel **csak Balaton-parti és kis-város (Sümeg) deal-ek** maradnak életképesek. Kispártos városokban (Pápa, Tapolca, Ajka, Várpalota) **a felújítandó/felújított spread 200 e/m² renoval kompresszálódik**.

Ami működik:
1. **Balaton-vonzat**: tópanorámás vagy közeli prémium pozícionálás → 1500-2000 e/m² exit
2. **Telek-bónusz**: ha a "lakás" valójában családi ház telekkel → családi ház piacon árazható
3. **Speciális termékek**: szerkezetkész padlástér, padlástér-beépítés, lakás-megosztás
4. **Vidéki kis-város teljes körű alacsony belépés**: Sümeg 313 e/m² entry → 800-900 exit (de exit ár volatil)

Ami **NEM** működik korrigált költséggel:
- Pápa / Tapolca / Ajka / Várpalota klasszikus tégla-flip
- Veszprém Belváros (felújítandó-felújított spread <200 e/m²)
- Berhida / Devecser / Zirc kispiac
